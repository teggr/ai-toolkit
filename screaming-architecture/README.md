---
name: Screaming Architecture
description: Agent plugin for designing and reviewing feature-first architecture so package structure communicates business intent.
---

This Agent plugin is a valid [Agent Plugin 1.0](https://agent-plugins.org/) package. You can install it directly in VS Code by pointing the plugin installer at this directory.

This Agent plugin includes:

- `skills/screaming-architecture/SKILL.md` - an invocable skill for designing, creating, and reviewing codebase architecture using Screaming Architecture and package-by-feature principles.
- `skills/screaming-architecture/docs/docs.md` - a practical workflow with branching decisions, anti-pattern checks, and completion criteria.
- `instructions/screaming-architecture.md` - Copilot agent instructions that reference and prioritize the `screaming-architecture` skill for architecture design/review work.
