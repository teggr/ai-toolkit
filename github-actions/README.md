---
name: GitHub Actions
description: Agent plugin for skills for working with GitHub Actions workflows, including setting up and maintaining common actions.
---

This Agent plugin is a valid [Agent Plugin 1.0](https://agent-plugins.org/) package. You can install it directly in VS Code by pointing the plugin installer at this directory.

This Agent plugin includes:

- `skills/setup-java/SKILL.md` — a reference skill for using the `actions/setup-java` action to install Java in GitHub Actions workflows, covering inputs, caching, distributions, publishing, and full workflow examples.
- `skills/setup-java/docs/docs.md` — supporting documentation with reference content sourced from the official `actions/setup-java` repository.
