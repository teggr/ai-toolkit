---
name: Deploy4j
description: Agent plugin for deploy4j installation and deployment guidance for setting up and operating deploy4j-based app delivery.
---

This Agent plugin is a valid [Agent Plugin 1.0](https://agent-plugins.org/) package. You can install it directly in VS Code by pointing the plugin installer at this directory.

This Agent plugin includes:

- `skills/deploy4j/SKILL.md` — a reference skill for installing deploy4j, initializing project configuration, managing secrets, and running setup/deploy workflows.
- `skills/deploy4j/docs/docs.md` — supporting documentation with CLI-first workflows, verification commands, and fallback links to deploy4j website documentation.
