---
name: Deploy4j
description: Bundle of deploy4j installation and deployment guidance for setting up and operating deploy4j-based app delivery.
---

This bundle is a valid [Agent Plugin 1.0](https://agent-plugins.org/) package. You can install it directly in VS Code by pointing the plugin installer at this directory, or use `jbang AiToolkit.java plugin package deploy4j` to download and zip it.

This bundle includes:

- `skills/deploy4j/SKILL.md` — a reference skill for installing deploy4j, initializing project configuration, managing secrets, and running setup/deploy workflows.
- `skills/deploy4j/docs/docs.md` — supporting documentation with CLI-first workflows, verification commands, and fallback links to deploy4j website documentation.
