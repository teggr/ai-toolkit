This Agent plugin is a valid [Agent Plugin 1.0](https://agent-plugins.org/) package. You can install it directly in VS Code by pointing the plugin installer at this directory.

This Agent plugin includes:

- `agents/discovery.md` — a discovery agent focused on clarifying goals, scope, dependencies, risks, and unknowns before planning.
- Empty `instructions/` and `skills/` directories so the Agent plugin keeps the standard toolkit structure and can grow over time.
- Prompt files are legacy; add new reusable behavior as skills.
