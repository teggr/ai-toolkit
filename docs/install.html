Install Help

Install ai-toolkit agent plugins

Use the JBang-based installer to install agent plugins into your own environment, whether that is a local .github folder, a global ~/.copilot folder, or a custom target.

Before you start

You need Java and JBang available on your machine. If JBang is not installed yet, use the official setup guide first.

Install JBang JBang docs

Three ways to use it

  • Run the installer directly from GitHub with JBang — no clone needed.
  • Clone with git, then use the embedded install instructions to choose agent plugins.
  • Download raw files with curl if you prefer manual control over the install root.

Option 1: JBang from GitHub

Run the installer directly from the GitHub-hosted AiToolkit.java URL. Requires Java 21+ and JBang, but no local copy of the repository.

List available agent plugins

jbang https://github.com/teggr/ai-toolkit/blob/main/AiToolkit.java list

Install an agent plugin into your environment

jbang https://github.com/teggr/ai-toolkit/blob/main/AiToolkit.java install discovery

Show CLI help

jbang https://github.com/teggr/ai-toolkit/blob/main/AiToolkit.java --help

Option 2: clone with git

Clone the repository first, then use the embedded install guidance to choose agent plugins and target roots.

git clone https://github.com/teggr/ai-toolkit
cd ai-toolkit
jbang AiToolkit.java list
jbang AiToolkit.java install discovery

Option 3: install as a VS Code plugin

The canonical source for this workflow is the official VS Code guide Discover and install plugins.

Repository maintenance skills

Use the create-new-plugin skill for internal scaffolding and structure checks when evolving agent plugin layouts.

Install from VS Code

  • Open the Extensions view and search for @agentPlugins, or open Agent Customizations.
  • Install from a marketplace, from source, or register a local plugin directory with chat.pluginLocations.
  • Enable the plugin in the Agent Plugins - Installed view once it appears.

Option 4: raw files via curl

Download the raw files you need and place them into your preferred install root.

Download the skill files

curl -L -O https://raw.githubusercontent.com/teggr/ai-toolkit/main/ai-toolkit/skills/ai-toolkit/SKILL.md
curl -L -O https://raw.githubusercontent.com/teggr/ai-toolkit/main/ai-toolkit/skills/ai-toolkit/docs/docs.md
Use this path when you want to fetch raw files first, then arrange them under ./.github, ~/.copilot, or another target you control.

Uninstall an agent plugin

Remove a previously installed agent plugin. Mirrors the same options as install.

Remove from the current repository

jbang AiToolkit.java uninstall discovery

Remove from the global folder

jbang AiToolkit.java uninstall --global --force discovery

Remove using the remote installer (no clone)

jbang https://github.com/teggr/ai-toolkit/blob/main/AiToolkit.java uninstall discovery

What happens when you install

  • The installer fetches agent plugin files from teggr/ai-toolkit.
  • Existing files are left alone unless you use --force or choose overwrite in the prompt.
  • Use jbang ... install <agent-plugin> with any agent plugin name shown by list, then target the environment you want.
  • If a plugin includes an MCP server definition (.mcp.json), the installer merges its mcpServers entries into the target .mcp.json (e.g. .mcp.json at the workspace root or ~/.copilot/.mcp.json globally). Uninstalling removes those entries.
