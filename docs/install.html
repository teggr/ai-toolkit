Install ai-toolkit bundles

Use the JBang-based installer in this repository to list available bundles and copy them into your local .github folder or your global ~/.copilot folder.

Before you start

You need Java and JBang available on your machine. If JBang is not installed yet, use the official setup guide first.

Install JBang JBang docs

Two ways to use it

  • Download or clone this repository, then run AiToolkit.java locally.
  • Skip the download and run the same installer directly from the raw GitHub URL.

Option 1: Download or clone the repository

If you already have this repository locally, run the installer from the repo root.

List available bundles

jbang AiToolkit.java list

Install a bundle into the current repository

jbang AiToolkit.java install discovery

Useful install variants

jbang AiToolkit.java install --target /tmp/copilot-resources discovery
jbang AiToolkit.java install --global --force discovery
By default the installer writes into ./.github. Use --global to install into your user-level ~/.copilot folder instead.

Option 2: Run directly from GitHub with JBang

This path is useful when you want the installer without cloning the repository first.

List available bundles

jbang https://raw.githubusercontent.com/teggr/ai-toolkit/main/AiToolkit.java list

Install a bundle

jbang https://raw.githubusercontent.com/teggr/ai-toolkit/main/AiToolkit.java install discovery

Show CLI help

jbang https://raw.githubusercontent.com/teggr/ai-toolkit/main/AiToolkit.java --help

What happens when you install

  • The installer fetches bundle files from teggr/ai-toolkit.
  • Existing files are left alone unless you use --force or choose overwrite in the prompt.
  • Use jbang ... install <bundle> with any bundle name shown by list.
