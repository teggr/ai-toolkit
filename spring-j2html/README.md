---
name: Spring j2html
description: Bundle of j2html-extensions resources for Copilot customizations, covering Spring Boot integration, Bootstrap, HTMX, and template engine usage.
---

This bundle is a valid [Agent Plugin 1.0](https://agent-plugins.org/) package. You can install it directly in VS Code by pointing the plugin installer at this directory, or use `jbang AiToolkit.java plugin package spring-j2html` to download and zip it.

This bundle includes:

- `skills/j2html-extensions/SKILL.md` — a reference skill for working with the [j2html-extensions](https://github.com/teggr/j2html-extensions) library in Spring Boot applications.
- `skills/j2html-extensions/docs/docs.md` — supporting documentation covering Maven setup, the Spring Boot starter, core extensions, Bootstrap classes, HTMX attributes, and the j2html template engine.
