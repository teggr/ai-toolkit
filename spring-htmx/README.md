---

This Agent plugin is a valid [Agent Plugin 1.0](https://agent-plugins.org/) package. You can install it directly in VS Code by pointing the plugin installer at this directory.

This Agent plugin includes:

- `skills/spring-htmx/SKILL.md` — a reference skill for working with the `htmx-spring-boot` library in Spring Boot applications.
- `skills/spring-htmx/docs/docs.md` — supporting documentation covering setup, request and response handling, security integration, and Thymeleaf usage.
